# protocol

The app-neutral host-device Bluetooth protocol: a versioned spec (`SPEC.md`) with capability discovery, and golden byte vectors that both firmware and host implementations test against. Any change bumps the protocol version (`proto-v<semver>` tags). Code: MIT; spec text: CC-BY-4.0.
