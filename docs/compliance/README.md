# docs/compliance

Regulatory records: the radio module's FCC ID and integration-guide checklist, Part 15B SDoC material, EU conformity (RED, RoHS, WEEE, CRA), and pre-scan results.

- [`fcc.md`](fcc.md): ESP32-S3-MINI-1 (FCC ID 2AC7Z-ESPS3MINI1) integration
  constraints, host label text, user manual statements and the Part 15B SDoC
  checklist.
- [`eu.md`](eu.md): EU legislation per variant (RED including cybersecurity,
  Cyber Resilience Act, RoHS, REACH, WEEE, GPSR, UN R10), harmonised standards
  with their OJ references, conformity route, declaration and technical file,
  markings and user information, and the design-affecting checklist
  ([ADR-0009](../decisions/ADR-0009-eu-compliance.md)).
