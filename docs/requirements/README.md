# docs/requirements

Requirements and constraints. Start with [`constraints.md`](constraints.md).

- [`constraints.md`](constraints.md): the hard constraints, in prose.
- [`requirements.md`](requirements.md): numbered, testable requirements
  (`REQ-<area>-NNN`) derived from the constraints, with verification methods,
  status and traceability to issues.
- [`radio-connectors.md`](radio-connectors.md): radio-side connectors and pinouts.
- [`pcb-fabrication.md`](pcb-fabrication.md): PCB fabrication and
  passive-component rules.
