# hardware/lib

Project-local KiCad libraries shared by all boards: `symbols/` (`.kicad_sym`), `footprints/` (`<lib>.pretty/`), `3dmodels/` (STEP). Reference them from board library tables using `${KIPRJMOD}`-relative paths. Record the source and license of any imported third-party model or footprint in this README.
